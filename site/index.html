Released September 7, 2026

v1.8.6 makes long Brainstorm runs recoverable.

This maintenance release handles provider limits deliberately, restores ChatGPT login-page detection, and clears high-risk development dependency alerts.

01

Retry, Skip, or Cancel

Brainstorm pauses on limits, bridge timeouts, and structured provider errors. Skip uses a safe placeholder and never relays raw error text.

02

Graph v4 boundary

Older snapshots cannot silently adopt the new recovery semantics, and reserved turns clean up safely after retry or cancellation.

03

ChatGPT adapter v7

The redesigned login form is recognized without widening the provider's URL or permission boundary.

04

Dependency hardening

Four High Dependabot alerts were resolved; full and production audits reported no known vulnerabilities at release time.

With thanks to Rumi-3653 for the adapter contribution and ufgeorge for the Brainstorm report.

Local-first by design

Your sessions stay yours.

The app coordinates real provider pages while keeping its own state on your computer. It adds workflow, not another conversation cloud.

  1. 1

    Sign in directly

    Each provider runs in a separate local WebView profile. The app never asks for your password.

  2. 2

    Choose a workflow

    Select parallel targets or assign structured roles; unavailable providers are surfaced before a serial run.

  3. 3

    Review one transcript

    Read chronological results, inspect the live provider when needed, then continue or start a clean conversation.

A narrow trust boundary

No API keys. No telemetry. No hidden relay.

Your prompts go to the providers you select. The app does not add an account server or analytics layer between you and them.

✓Provider webviews receive zero Tauri permissions
  • 01

    Cookies and provider profiles remain in local app data, isolated per provider.

  • 02

    Only the bundled local control pane can call app commands.

  • 03

    Adapter updates are schema-validated JSON and cannot expand bundled URL scopes.

  • 04

    Snapshots are opt-in, local, and use one of four frozen privacy tiers.

  • 05

    Diagnostics exclude page text, input values, cookies, storage, queries, and fragments.

  • 06

    Exports, debug bundles, and share actions require an explicit user action.

Honest boundaries

Automation follows changing websites.

Evidence is reported as evidence—not as a promise that every provider, account, or platform path works today.

Provider changes

A DOM or login-flow change can temporarily break automatic input, send, or completion detection until an adapter update ships.

Account rules remain

Subscriptions, quotas, regional rules, and challenges still apply. Claude requires login; Gemini and Grok blocks need user action.

Platform evidence differs

Windows launch is verified, macOS Apple Silicon is partially verified, and Linux packaging is currently CI-only.

v1.8.6 live gates

A full live 48-contribution recovery run and all live login/challenge paths were not manually reverified for this release.

Frozen product scope

No fifth provider, marketplace, graph editor, embedded terminal agent, telemetry, self-updater, or new snapshot schema is planned.
